# Race Time Calculator

The *Race Time Calculator* is a lightweight JavaScript web application
featuring a collection of calculators for motorsport timing. It helps you
quickly calculate race durations, average lap times, and the number of laps
based on a few simple inputs.

The application provides the following calculations:

- Total race time — Calculate the total time based on the number of laps and the lap time.
- Average lap time — Calculate the average lap time based on the total time and the number of laps.
- Number of laps — Calculate the number of laps that can be completed within a given total time based on the lap time.
